# Online Food Ordering App

## Project Overview

The Online Food Ordering App is a software project designed to organize and manage the development of an online food ordering platform.

The project follows Agile Scrum methodology to divide development activities into manageable user stories and track their progress through a GitHub Projects board.

## Project Objectives

- Implement customer login functionality.
- Enable customers to browse restaurants and menus.
- Provide shopping cart functionality.
- Support online order placement.
- Enable customers to track their orders.

## Project Management

Project Management Tool: GitHub Projects

Methodology: Agile Scrum

Project Board: Online Food Ordering - Scrum Project

## User Stories

1. Customer Login
2. Browse Restaurants and Menu
3. Shopping Cart
4. Order Placement
5. Order Tracking
